# Agent Instructions

For requests to explain a complex question deeply, build a "Why First" learning
page, create an analogy-first knowledge chain, or generate an interactive
teaching page:

1. Read `skills/deepwhy/SKILL.md` completely.
2. Follow its progressive reference-loading instructions and use the bundled
   scripts and template.
3. Keep the output standalone and portable. Do not require the DeepWhy product,
   an account, or a backend.
4. Ask for explicit confirmation before installing Manim. If installation is
   declined or fails, use SVG/SMIL.
5. Treat example content as a structural example, not as reusable facts.

Do not use DeepWhy for simple factual answers, API documentation, or ordinary
marketing pages.
